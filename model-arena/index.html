2 Contestant Models ▾

The prompt is sent to every enabled contestant. Edit the model ID to match exactly what the provider expects (model names change over time).

3 Judge Panel ▾

Each enabled judge independently scores every answer blind. Use several judges (ideally from different providers) for a fairer vote. Answers are anonymised as Answer A / B / C… and shuffled per judge to reduce position bias.
